# 🚦 Accident Severity Prediction

This project predicts the **severity of road accidents** (`Slight`, `Serious`, or `Fatal`) using machine learning models trained on accident data.

---

## 📊 Features
- Machine learning classification using Random Forest, Decision Tree, Logistic Regression, and Gradient Boosting.
- SMOTE applied for class balancing.
- Streamlit web app for real-time prediction.
- Cleaned and preprocessed dataset stored in `/data/processed`.

---

## 🧠 Tech Stack
- Python (Pandas, Scikit-learn, Imbalanced-learn)
- Streamlit (for web app)
- GitHub for version control
